# FX 简单! · 量化辅助台

B站小游戏「FX 简单!」(<https://www.bilibili.com/toy/fx-simple/index.html>) 的 Tampermonkey 辅助脚本。
**模拟盘游戏**，不接任何真实资金。

## 双引擎

| 引擎 | 适用模式 | 依据 | 实测 |
|---|---|---|---|
| **漂移引擎**（白盒） | 模拟行情 / 每日挑战 | 解析 `tickSim()` 的正弦漂移项 | 145 秒 **19 笔胜率 84.2%**，权益 +58% |
| **指标引擎**（黑盒） | 真实回放 / 经典战役 | EMA/MACD/RSI/布林 五因子评分 | 随机游走里无 edge，仅作回放模式的兜底 |

### 漂移引擎：为什么有效

`tickSim()` 每 1500ms 一跳：

```js
const drift = Math.sin(Date.now() / 13000 + index * 2 + marketIndex * .7) * .00036;
const close = open * (1 + drift + (Math.random() - .5) * .0042 + shock + newsEffect);
```

`drift` 只依赖 `Date.now()` 与品种索引 —— **完全可解析**。单 tick 时噪声 σ=0.121% 盖过 drift 的 0.036%，
但它是周期 ≈81.7 秒的正弦波：累积 10–27 tick 后达 0.3–0.6%，而噪声只按 √n 长到 0.42%，信噪比反超。

实测方向命中率（漂移累积 >0.2% 时）：

| 持有期 | 命中率 | 样本 |
|---|---|---|
| 10 tick (15s) | 80.0% | 714 |
| 20 tick (30s) | 77.6% | 763 |
| 27 tick (40.5s) | 74.2% | 667 |
| 40 tick (60s) | 60.1% | 401 |
| 54 tick (81s) | 无样本（整周期正弦积分归零） | — |

持有期**动态**取 `argmax |漂移累积| / √H`（H ∈ [8,30]），比固定 H=12 的平均漂移累积高 **53.8%**。
7 个品种的相位相差 2 rad（114.6°），同一时刻总有 2–4 个品种处于强漂移区 → 并发持仓分散跳空风险。

### 新闻偏置

6 个新闻模板里 4 个带方向性 bias，生效 5–8 tick：

```js
let newsEffect = activeSimNews?.bias?.[pair.id] || 0;
newsEffect *= .25 + Math.random() * 1.1;
if (Math.random() < .24) newsEffect *= -.6;   // 76% 概率与 bias 同向
```

模板可由 `#tickerTrack` 的 `【tag】title` 文本匹配查出。新闻与漂移同向 → 仓位 ×1.3，反向 → ×0.6。

## 安装

1. 装 [Tampermonkey](https://www.tampermonkey.net/documentation.php)（Chrome / Edge）。
2. 新建脚本 → 粘贴 `fx-quant.user.js` 全文 → 保存。
3. 打开游戏页，左下角出现「FX 量化辅助台」。

脚本只在游戏 iframe（`www.bilibilitoy.com/toy/fx-simple/*`）内运行。

## 风控与定量

**漂移引擎**：两条退出路径 ——

1. **零交叉反手**（优先）：每轮重算 `argmax |漂移|/√H`，若从现在起的最优窗口已指向反面，
   说明剩余持有期是负期望 → 立即平仓并同轮反手（冷却只拦同向重进，反手放行）。
   实测 60 秒内 7 笔全部走这条路，比等到期多赚 3–5 个百分点。
2. **到期平仓**（`barCount >= 开仓时 + H`）：漂移累积兑现完毕。

外加**止损随漂移强度缩放**：

```
止损 = clamp(0.25 + |漂移累积| / 0.15% × 0.05, 25%, 50%)
```

漂移 0.15% 的仓止损 30%，漂移 0.75% 以上的仓放宽到 50% —— 上限 50% 是因为游戏在 60% 会弹窗并冻结行情。
实测值域 [0.32, 0.45]，零触发。

**指标引擎**：止损 40% / 止盈 90% / 反转（评分反向 ≥30）/ 时间止损（20 bar 未盈利）。

**定量（两引擎共用）**：

- **半凯利**：从游戏自己的平仓记录在线估 `p` 与赔率 `b`，`f* = p − (1−p)/b`，取半凯利并夹在 [8%, 25%]；
  样本 < 10 笔时回落到 12%。面板「风险」显示实时凯利值，点击可切换成固定 5/10/15/20/30%。
- **货币敞口去重**：`EUR/USD 做多 = +EUR −USD`，任一货币净名义超过「权益 × 5」就按比例缩仓；
  缩到低于 $10 则跳过该信号。实测 4 笔并发时 EUR 净敞口 70980 / 上限 70929 —— 刚好卡住。
- 同品种平仓后 15 秒内不重进；并发上限 4 笔（挑战模式受游戏限制最多 5 笔）。

## 参数默认值

| 参数 | 值 | 依据 |
|---|---|---|
| 杠杆 | 30× | 单位保证金净收益随杠杆上升（drift 0.45% ≫ 费率），但 shock 最大 0.95%：lev=100 一次跳空即爆仓，lev=30 最坏 1.37%×30=41% 保证金 |
| 单笔风险 | 半凯利，夹在 [8%, 25%] | 实测胜率 90.5% → 凯利 f*≈0.8，半凯利 0.4 被上限压到 25% |
| 并发持仓 | 4 | 7 品种相位分散，噪声独立 |
| 漂移阈值 | 0.15% | 低于此值噪声占优 |

## 实测对比

| 版本 | 引擎 | 时长 | 结果 |
|---|---|---|---|
| v1.1 | 技术指标 | 150 秒 | 15 笔，权益 −7.5%，止盈 0 次 |
| v1.2 | 漂移相位 | 145 秒 | 19 笔，胜率 84.2%，权益 +58%，零止损 |
| v1.2+ | 漂移 + 凯利 + 敞口去重 | 145 秒 | 21 笔，**胜率 90.5%**，权益 +41.9%，零止损 |

v1.1 的结论现在有了对照：随机游走里技术指标无 edge，手续费磨损是净损失；
而 tickSim 的确定性漂移项是真实可提取的 edge。

## 逆向得到的游戏规则

| 项 | 值 |
|---|---|

## 数据通道

1. **游戏 API（首选）**：页面在 `document.modelContext` 存在时注册 4 个工具 ——
   `read_fx_game_state` / `place_fx_trade` / `close_fx_trade` / `advance_real_fx_day`，
   `execute` 闭包直接持有内部 `state`。脚本在 `document-start` 用两条互为备份的路径装 polyfill
   （`unsafeWindow.document` 直挂 + 注入 `<script>` 到页面主世界）。
2. **框架 API**：读 `fx-heartbeat-save-v3` 拿游戏自己写的 `sim` K 线。
3. **DOM**：API 不可用时读 `#currentPrice`/`#equity`，点 `#longBtn`/`#shortBtn`/`#nextDayBtn`。

## 架构与性能

分层（自下而上）：桥（双通道注入）→ 数据（快照/序列/指标）→ 引擎（漂移/指标/风控/定量）→ 执行（API 优先、DOM 兜底）→ UI（diff 渲染）。

**实测（Edge + CDP Performance metrics，15 秒全自动）**：

| 项 | 优化前 | 优化后 | 倍数 | 做法 |
|---|---|---|---|---|
| `Math.sin` | 7 759/s | **27/s** | 287× | 正弦和用闭式解 + 和角公式查表 |
| `JSON.parse` | 19.3/s（1.16 MB/s） | **0.6/s** | 32× | 存档字符串引用未变即复用上次解析 |
| `toLocaleString` | 34.7/s | 18.6/s | 1.9× | 复用 `Intl.NumberFormat` 实例 + 跳过漂移模式的指标渲染 |
| JS 执行占比 | 0.05% 单核 | 0.05% | — | 本来就不是瓶颈 |
| 堆内存 | 8.0 MB | 7.9 MB | — | — |

关键优化是**正弦和的闭式解**：

```
Σ_{k=0..H-1} sin(θ + kΔ) = sin(HΔ/2)/sin(Δ/2) · sin(θ + (H-1)Δ/2)
```

再套和角公式 `sin(θ+φ) = sinθ·cosφ + cosθ·sinφ`，每个品种每轮只需 2 次三角函数，
其余 23 个候选持有期全是乘加。单测断言与原始循环求和在 1e-9 内一致（残差来自 `t0/13000 ≈ 1.3e8` 的 double 精度极限，相对信号量级 3.6e-4 只有 3e-8 相对误差）。

**其它清理**：

- 漂移模式不再计算 7 品种 × 6 指标（既不用于下单也不用于显示）
- `step()` 65 行 → 12 行（拆为 `trackTick / trackNews / collectContext / executePlan / advancePlayback`）
- `buildUI()` 125 行 → 12 行（模板提为 `PANEL_HTML`，拆出 `bindRefs / wireEvents`）
- `renderPanel()` 79 行 → 8 行（拆为 `renderDriftPanel / renderIndicatorPanel / renderAccountPanel`）
- 预期内的降级路径（CSP 阻断、隐私模式、脏存档）在 catch 处标注意图；主世界注入被阻断会写进日志

## 已知限制

- **这是白盒套利**：利用 `tickSim` 的实现细节（不读未来、不改状态），真实市场不存在这种确定性。
- 挑战模式的行情由 `challengeSim` 驱动且不存档。漂移引擎**不需要 K 线**（相位可解析），进模式即可交易；
  但指标区因无 K 线显示为空 —— 不会拿模拟市场 K 线顶替（那是无关序列）。
- 脚本只自动清理**没有 `modalAction`** 的弹窗（平仓结果、战役结束、风控告警）。
  带 action 的（重新开始 / 借款 / 还款 / 金盆洗手）一律留给玩家自己点。
- 游戏每次平仓都弹模态框，脚本每 1.5 秒自动点掉；期间手动操作会被打断。
- 漂移引擎在 `challenge` 模式需 `marketIndex = 1`（相位 +0.7），已按模式区分；未做长时间实测。
